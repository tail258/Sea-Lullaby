**Sea Lullaby · 海之摇篮** is an Obsidian theme for reading and writing at an unhurried pace. A narrow slate ribbon anchors the interface; mist-blue sidebars frame a bright note surface. Warm sand headings, gentle links, and generous line spacing keep attention on the page.

## Design

| A softer workspace | A clear writing surface | Details that settle in |
| :--- | :--- | :--- |
| Pale navigation, a slim dark ribbon, and distinct selection states. | Near-white notes, slate text, a measured line width, and six heading levels. | Coordinated links, tags, tables, quotes, code blocks, and callouts. |

### Palette

| Color | Hex | Use |
| :--- | :--- | :--- |
| **Sea** | `#404E5B` | Ribbon and deepest interface tone |
| **Harbor** | `#677B8F` | Navigation and secondary accents |
| **Mist** | `#8FA0B8` | Gentle highlights |
| **Stone** | `#948F8C` | Warm counterpoint |
| **Silver** | `#CCC9C6` | Soft neutral detail |
| **Sand** | `#AE8B56` | Links and warm heading accents |
| **Paper** | `#FFFFFF` | Note background |

The theme intentionally keeps the same light reading palette in both Obsidian's light and dark appearance settings. Fonts may vary with what is installed on your system.

## Installation

**Requires Obsidian 1.13.0 or later.**

1. [Download this repository](https://github.com/tail258/Sea-Lullaby/archive/refs/heads/main.zip) and extract it.
2. Create `.obsidian/themes/Sea Lullaby/` inside your vault.
3. Copy `theme.css` and `manifest.json` into that folder.
4. In Obsidian, open **Settings → Appearance** and select **Sea Lullaby**. Restart Obsidian if it does not appear immediately.

```text
.obsidian/
└── themes/
    └── Sea Lullaby/
        ├── manifest.json
        └── theme.css
```
